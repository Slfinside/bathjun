# v2.0.0 にまとめる機能

以下は v2.0.0 の予定で、現在の版に実装済みの機能ではありません。

| 機能 | 目標 |
| --- | --- |
| 自動バックアップ・復元 | 定期保存と更新前の保存、管理画面からの復元。メンバー・予約・認証・リンクを含むデータを保護し、保存場所と保持数を設定する |
| 起動方法の記憶 | 公開／ローカルを記憶し、Windowsへのサインイン後も元のモードで起動。公開の準備・失敗を管理画面で確認できるようにする |
| 実際の入浴状態 | 「入った／出た」の操作で状態を共有。予約時刻による推定と区別し、押し忘れや予定とのずれも扱う |
| 端末単位のログイン管理 | 端末一覧・最終利用を確認し、紛失端末だけのログイン・通知登録等を解除できるようにする |
| 更新配布元の確認 | 更新ファイルの署名を検証する。署名鍵の安全な保管と公開鍵の配布方法を決め、製品名やチェックサムだけの確認から強化する |

既存データを保持する移行を前提にします。バックアップは認証情報や家族用リンクも含むため、GitHubや配布物には含めません。署名は、Windowsの警告表示に関わるAuthenticode署名と、アプリ内で配布元を検証する署名を区別して設計します。


## 7日連続で予定どおり入浴したときの特典（検討中）

7日連続で宣言した予定どおりに入浴できた場合、予約に使える特典を付与する案。入らなかった日は成功に数えず、連続記録をリセットする。

候補は「入浴時間の上限を30分延ばせる券」。1回限り・期限7日・保有1枚を提案中で、確定仕様ではない。ほかの人の予約と重なったり、家庭の入浴時間帯を超えたりする使い方は認めない。「予約する順番を1つ早める券」も比較候補。

入浴したかの記録は本人の自己申告とする。「入りました」ボタン等で記録し、カメラ・人感センサーによる入浴判定は行わない。成功とみなす開始・終了時刻の許容幅、予定を変更した場合や様子見から予約した場合の扱い、特典の具体的な内容は実装前に決める。現在の版には実装しない。


追加候補：

- 再抽選権：誰も予約していない段階で、1回だけ引き直す案。全員の順番が変わるため、発動可能なタイミングを制限する。
- 追い抜かし権：未予約の人を1人だけ追い越す案。確定済みの予約・開始時刻は変えない。
- 達成時に「上限延長／再抽選／追い抜かし」から1つ選ぶ方式も検討する。

これらも候補段階であり、今回の更新には含めない。
