# 利用者向け：ふろきゅ～の使い方

この文書はv2.0.0-beta1の手順です。[日付・予約の区切り](calendar-days.md)と曜日ごとの自動予約にも対応しています。

サーバーを設定する人は[管理者向けガイド](administrator-guide.md)を参照してください。

## 初めて使う

1. 管理者から受け取った家族用リンク、またはサーバー端末のQRコードをSafariなどで開きます。
2. 家族共通の合い言葉を入力します。
3. 自分の名前を選び、自分用のパスワード（4〜128文字）を設定します。他の人の名前を選ばないでください。
4. 自分のアイコンの絵文字と色を選びます。16色の候補と自由な色指定を使えます。
5. 「パスキーを登録」から登録すると、次回はFace ID・Windows Hello・PINなどでログインできます。顔・指紋の情報はふろきゅ～のサーバーには送りません。

ログイン状態が残っていれば、そのまま利用できます。ログアウト後もパスキーなら合い言葉と個別パスワードの入力を省略できます。パスワードを忘れた場合は管理者に変更を依頼してください。

## iPhoneのホーム画面と通知

1. Safariで家族用リンクを開き、共有メニューから「ホーム画面に追加」します。
2. 追加したアイコンから開いてログインします。
3. 「通知を受け取る」を押して許可します。iOS 16.4以降・HTTPS接続が必要です。

通知は「事前希望が確定した」「事前希望を確定できなかった」「予約する番になった」「入浴開始前」の4種類です。「ログイン・通知の設定」でそれぞれ有効・無効を選べます。入浴前の分数は本人が1〜180分前で設定し、初期値は10分前です。種類と分数は自分の端末間で共通、通知の許可は端末ごとです。予約や通知登録が設定した通知時刻を過ぎていれば、開始前に限りすぐ送ります。未確定の希望は入浴前通知の対象になりません。変更・キャンセルに合わせて通知予定も更新します。OS・通信状況によって遅れる場合があり、サーバー停止中には送れません。

登録済みの設定案内は隠れます。再設定・アイコン変更は「ログイン・通知の設定」を開いてください。通知の許可を外したときは再び案内が出ます。

## 順番を決めて予約する

「昨日／今日／明日／明後日」で表示を切り替えます。「今日」は日本時間の0:00で切り替わり、予約・スタンプは開始時刻で所属日を決めます。区切りが初期7:00なら、今日分は今日7:00〜翌7:00未満に開始する予約です。6:30〜7:30のように区切りをまたいでも前日分です。今朝の予約は「昨日」から確認してください。朝3:00でも当日分の抽選・予約を始められます。未来の分には事前希望を出せますが、先行抽選・予約はできません。

1. 抽選方式なら、当日の朝などに誰かが抽選ボタンを押します。結果は全端末で共通で、引き直しはできません。固定順なら設定された順番になります。
2. 自分の番になったら、空いている開始時刻と所要時間を選んで予約します。
3. 必要なら備考を書き、「時間変更不可」を選びます。事情を家族へ伝える表示です。

初期設定の所要時間は脱衣所に入ってから出るまで15〜90分です。予約済みの時間とは重ねられません。開始前なら予約を変更・取り消しできます。開始済みの予約は変更できません。

## 事前希望

表示できる未来の日も含め、抽選前・自分の番が来る前でも「事前希望」の大きな「希望を出す」ボタンから時刻・所要時間・理由を共有できます。希望は全員に見え、スケジュールにも薄い色と点線で表示されます。まだ予約は確定していません。

自分の順番が来たとき、希望が確定済みの予約と重ならなければ自動確定の対象になります。初期設定では下位の人の希望より順番を優先します。管理者がこの許容をオフにした場合は、ほかの希望とも重ならないことが条件です。18:00〜18:30と18:30〜19:00のように境界だけが一致する場合は重複ではありません。自分の番で確定できなかったときは、該当する通知を有効にしていればお知らせします。条件を満たさない間は未確定のままなので、時間を選び直すか家族と相談してください。希望は変更・取り消しできます。

## 入らない／様子見

「入らない/様子見」は、その日の予約順の最後へ移動する操作です。予約意思はまだないけれど後で入る人も使えます。複数人が選ぶと選んだ順に末尾へ並びます。

未来の予約・希望がある場合は確認後に取り消します。様子見のまま希望を出すことも、末尾の自分の番で予約することもできます。「通常の順番に戻す」で元の位置に戻れます。

## 毎日自動で「入らない/様子見」にする

「ログイン・通知の設定 → 毎日の予約設定」で、本人が有効・無効を選べます。初期はオフです。次に順番を決める夜から、予約する順番を自動で末尾へ回します。予約済みの時刻や、先に出してある希望を自動で取り消すことはありません。

その夜だけ戻したい場合は「通常の順番に戻す」を押します。再読み込みしてもその夜の選択は維持し、次の夜はまた設定に従います。今日すぐ様子見にする場合は通常の「入らない/様子見」を使ってください。自動設定が有効でも希望を出せ、末尾の自分の番で予約できます。

## 表示の見方

スケジュールは15分目盛りです。2時間以上の連続した空きは、前後の時刻付きの波線で省略します。

サーバー端末のダッシュボードの「入浴中」「入浴済」は予約時刻から判定します。実際の入退室を検知した表示ではありません。予約した時刻が変わった場合は、開始前に予約を変更してください。

家族用リンク・QR・合い言葉は家族以外へ共有しないでください。

## 予約を待っている人をつつく（開発版）

予約の順番一覧で、今予約する番の人に「つつく」が表示されます。押すと「お風呂を予約しましょう。」「つつかれました。あなたの予約を待っています。」という通知を送ります。自分自身には表示されません。

同じ人をつつけるのは、家族全員・すべての端末の操作を合わせて1時間に1回までです。その間は灰色の「あと○分」になり、押せません。別の夜の予約へ切り替えても、同じ人への制限は引き継ぎます。

受け手が通知未設定・無効の場合も押せません。受け手はメニューの「設定」→「通知の種類」→「つつかれた」で個別に切り替えられます。予約が済んだ人や、すでに順番が変わった人には送信待ちの通知を送りません。実際の通知受信には、従来どおり端末での通知設定が必要です。

## プレゼント到着のお知らせ（開発版）

未受取のプレゼントがあると、メニューの印に加え、メニューの下に「📦 プレゼントが届いています。」という吹き出しが表示されます。吹き出しをタップするとプレゼントボックスへ進みます。

メニューを開いている間とプレゼントボックス・配布履歴の画面では吹き出しを隠します。未受取のものが残っていれば、ホームへ戻ると再表示します。すべて受け取ると消えます。

## v2.0.0-beta1のスタンプと完了報告

入浴完了の報告期限は管理者が変更できます（初期はこの画面から終了後3分、ダッシュボードから1分）。予約の終了時に報告を促す通知を送り、設定で個別に止められます。

「入らない/様子見」は「−」のまま保留します。初期は2日続けて入らなければ、2日目の入浴時間帯が終わった時点で両日失敗になります。次の日に入浴を完了して期限内に報告すれば、前日の保留も成功になります。土曜の保留が日曜に成功になった場合も、前週の7枠がそろえば報酬を受け取れます。詳しくは[新機能ガイド](v2-preview-guide.md)を参照してください。

### おふろスタンプとスタンプのインク

- **おふろスタンプ**：お風呂の絵柄のスタンプ。専用インクを使えば、お風呂に入ったことの証明になる。
- **スタンプのインク**：おふろスタンプ専用のインク。お風呂に入ったことの証明に使える。実は磁石にくっつく。

「メニュー → 持ち物」でおふろスタンプの「使う」を押し、今週・先週の今日までの未確定または失敗の日を選ぶと、インク1個を使って成功に変更できます。スタンプ本体はなくなりません。インクを持っていないと「使う」は無効です。インクからも同じ画面を開けますが、スタンプ本体も必要です。今日までの未確定「−」にも使えます。未来の日・成功済みの日・先々週以前には使えません。

使用履歴はスタンプカードの獲得履歴に残ります。予約や入浴完了報告は変更せず、カードが7日そろえば週間達成報酬を受け取れます。アイテム機能が無効の間は使えません。

プレゼントボックスと配布履歴の「説明を見る」を開くと、受け取り前にもアイテムの説明や使用条件を確認できます。説明は最初は折り畳まれており、開いても受取・使用は行いません。

## 曜日ごとの自動予約

「メニュー → 設定 → 曜日ごとの自動予約」で、曜日ごとに有効・無効、入浴の開始時刻・長さ・備考を設定します。初期はすべて無効です。時刻は日本時間です。区切りが7:00なら、月曜の3:00は火曜朝3:00の入浴になります。

自分の予約順が回ってきたら、サーバーが設定した時間を一度だけ自動送信します。空いていれば確定し、重なっていれば事前希望として残します。画面を開いておく必要はありません。保存当日も、自分の順番でまだ未実行なら適用します。すでに手入力した予約・希望・「入らない/様子見」は上書きしません。送った希望を取り消しても、その日は自動で出し直しません。設定変更は、当日未実行なら次に自分の順番が来た時点、実行済みなら次に該当する曜日から反映します。

順番が来て重なりがなければ、通常の事前希望と同じ条件で確定します。成功・失敗の通知も「事前希望が確定した」「事前希望を確定できなかった」の設定に従います。希望の時刻までサーバーが停止していた場合や、管理者の時間設定変更で希望を出せない場合は、確定できなかった旨を通知します。受付が終了した過去日分は後から出しません。アイテムは自動では使いません。

## beta1：事前の様子見と希望開始時刻の確定

「明日」「明後日」でも「入らない/様子見」を事前に共有・撤回できます。予約順が決まった際は末尾へ回ります。これを選んでも先に抽選したり、すぐにスタンプを失敗にしたりしません。

抽選済みの日の事前希望は、自分の予約順がまだでも、希望の開始時刻に空いていれば確定します。同じ日・前後の日の確定予約と、ほかの人の希望との重なりを確認し、重なっている場合は確定しません。終了と開始が同時刻なら重複ではありません。チケットの使用制限は維持します。サーバー停止中に開始していた場合も、入浴時間が残っていれば起動時に確認します。終了済みの希望は確定しません。

ホームと「スタンプカード」の「おふろスタンプを使う」からも、今週・先週を選んでインクを使えます。スタンプ本体とインクの両方が必要で、成功済み・未来の日・先々週以前には使えません。先週分で7日そろったときも、その週の報酬を一度だけ受け取れます。
