# 日付と予約・スタンプの区切り（v2.0.0-beta1）

この変更はv2.0.0-beta1のインストーラ版・ZIP版に含まれます。rc3以前には含まれていません。

「今日」と抽選の対象日は、日本時間の0:00で切り替えます。入浴できる時間帯の開始・終了設定は廃止し、予約とスタンプの所属日を決める区切り時刻だけを設定します。初期値は7:00です。

区切りが7:00なら、11月1日分は11月1日7:00以上、11月2日7:00未満に**開始する**予約です。

| 操作・予約 | 扱い |
| --- | --- |
| 11月1日3:00に「今日」を開く | 11月1日分。7:00以降に開始する予約を準備できる |
| 11月1日3:00に当日分を抽選 | 11月1日分の順番を決める。抽選時間の制限を有効にしている場合はその設定にも従う |
| 11月1日6:30〜7:30の予約 | 10月31日分。7:00をまたいでも開始時刻で所属日を決める |
| 11月2日6:30〜7:30の予約 | 11月1日分。終了後の報告も11月1日のスタンプに反映する |
| 今朝の予約を確認する | 「昨日」を開く。深夜・朝も初期表示は暦日の「今日」 |

日付の異なる予約同士も実際の時刻で重複を確認します。前日の予約が7:30まで続く場合、当日7:00〜7:30に重なる予約はできません。7:30ちょうどから続けて予約することはできます。希望の自動確定でも同じ判定を行います。

管理画面の「設定」→「予約・スタンプの区切り」で変更します。区切りは予約の刻み幅に合わせて指定し、変更は翌日分から適用します。連続して入らない場合の判定は、それぞれの日の区切り時刻が過ぎてから行います。確定した予約が区切りをまたぐ場合、完了報告の期限は実際の予約終了時刻から数えます。

既存データの更新では、記録済みの予約・希望・スタンプの所属日を動かしません。従来の入浴時間帯は履歴に保持し、新しい24時間の枠は翌日分から適用します。従来の終了が翌7:00なら区切り7:00を引き継ぎます。独自の翌朝終了時刻を設定していた場合はその時刻を引き継ぎます。

ダッシュボードは暦日の「今日」に固定せず、今入っている人や報告待ちの予約を優先して表示します。詳細表示は左に現在・次の人と共有QR、右に上から下へ時間が進むスケジュールを配置します。簡易・詳細のどちらにもメンバー一覧は表示しません。
