# 時刻を決めずに、おふろに使う時間だけ共有する

**v2.1.0-beta1で追加した機能です。**

「何時に入るかは後で決めたい。でも今日は長風呂にしたい」というときは、予約・事前希望の入力画面で **「時刻は決めない」** を選びます。所要時間と備考だけが家族に共有されます。

これは**未確定の希望**です。開始時刻も予約枠も確保しません。スケジュールには「時刻未定」として名前と所要時間をまとめて表示し、時刻付きの予約・希望とは分けます。自分の順番が来ても、時刻未定のまま自動確定することはありません。

あとから同じ入力画面を開き、「時刻は決めない」を外して開始時刻を選びます。通常の予約順・重複確認に従い、予約するか、時刻付きの希望として共有します。明日・明後日の希望にも使えます。確定済みの予約の変更や、未報告予約の取り直しではこのチェックボックスを表示しません。

## いつ開始時刻を決めるよう通知する？

次の**どちらか**を満たしたら、時刻未定の希望を出している本人だけに通知します。

1. 全員が、その日について予約・希望・「入らない/様子見」のいずれかを入力した。
2. 夜の残り時間に対して、これから必要なおふろの時間に余裕がなくなった。

入力がそろった条件では、翌朝の予定も「入力済み」に数えます。未来の日も、全員の入力がそろえば通知の対象です。

通知は「おふろの開始時刻を決めましょう」というお願いです。時刻を勝手に決めたり、予約順を飛ばして確定したりはしません。同じ端末には、同じ日・同じメンバーについて一度送信に成功したら重ねて送りません。複数の端末で通知を登録している場合は、それぞれに届きます。

## 「余裕がなくなった」の計算

管理者が決める **「夜の締め切り」** を基準にします。初期値は **翌2:00** です。

```text
これから必要な時間 × 1.2 ＋ 60分 ＞ 夜の締め切りまでの残り時間
```

左側が右側を**上回ったとき**が通知のタイミングです。同じ長さの間は通知しません。20%と1時間は、間隔や予定変更への余裕です。

例えば、これから必要な時間の合計が135分なら、余裕を含めると222分（3時間42分）です。締め切りが翌2:00の場合、22:18時点では残り222分で同じ長さです。その直後から条件を満たし、22:20には残り220分なので通知対象です。実際の計算は、入浴中の残り時間も考慮して更新します。

### 合計に入れる時間

| 状態 | 数える時間 |
| --- | --- |
| これから始まる夜の予約 | 予約した所要時間 |
| 夜の予約で入浴中 | 予約終了までの残り時間 |
| 予約の終了時刻を過ぎた／完了報告済み | 0分 |
| 時刻付きの夜の未確定希望 | 希望の所要時間。希望時刻を過ぎても、未確定なので全時間を数える |
| 時刻未定の希望 | 希望の所要時間。夜に入る想定として数える |
| 翌朝に始まる予約・希望 | 0分 |
| 入らない/様子見・未入力・無効なメンバー | 0分 |

**翌朝かどうかは開始時刻で判断します。** 初期設定なら翌2:00以降に始まる予定を計算から除きます。1:30〜2:30の予約は開始が2:00より前なので含めます。朝に入りたいことが決まっている場合は、開始時刻も入力してください。

未入力の人の所要時間は推測しません。全員の入力がそろう前でも、共有済みの時間だけで余裕がなくなれば通知します。同じ人の時間は二重に数えません。

## 設定と通知を受ける条件

- **管理者：** サーバー管理画面の「設定」→「夜の締め切り（翌日）」で変更します。これは通知用の目安で、予約の禁止時刻ではありません。予約日・スタンプを区切る時刻（初期7:00）とも別の設定です。保存後すぐ計算に反映されます。
- **本人：** クライアントの通知設定で「開始時刻を決めるお願い」を有効・無効にできます。初期は有効です。
- 通知には、その端末での通知許可・ログインと、サーバーの稼働が必要です。iPhoneではホーム画面への追加など、通常の通知と同じ条件が必要です。
- 夜の締め切り、またはその予約日が終わる時刻（初期は翌7:00）のうち、早い方を過ぎたら送りません。通知が無効・未登録なら、希望はそのまま共有されます。

時間だけの共有では入浴完了やスタンプ成功にはなりません。開始時刻を決め、通常どおり予約・完了報告してください。
