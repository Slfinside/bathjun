# ダッシュボードのLCD表示保護：調査とv2.0.0の方針

確認日：2026年10月29日。以下はLCD全般の一般的な説明で、特定の端末の寿命や故障を検証した結果ではありません。

## 小さな位置移動だけで十分か

**小刻みな移動だけでLCDの劣化を防げる、とは言えません。** 固定表示の一部を分散する補助にはなりますが、大きなカードや背景は同じ画素に留まりやすく、バックライトなどの経年劣化への対策とは別です。

LCDでは長時間の固定表示により、残像（image persistence / image retention）が起きることがあります。AppleはIPS液晶の残像と、非使用時のディスプレイ消灯・スクリーンセーバーを説明しています。HPの技術資料も、静止画を長時間表示し続けないことや、未使用時の消灯を勧め、まれに残像が元に戻らない場合もあるとしています。

## 動くグラデーションなら解決するか

画像を変化させることは固定表示を減らす補助になります。ただし、グラデーションを動かしても、その上の不透明なカードや文字が固定されていれば、固定表示は残ります。これだけで残像や劣化を完全に防ぐ保証はありません。

また、LCDの表示内容とバックライトの輝度は別です。暗い配色や黒い画面を描くだけでは、実際のバックライトが暗くなったり消灯したりするとは限りません。内容に応じた輝度制御の有無なども機種によって違います。

## v2.0.0の予定

- 日中・深夜など、画面を使わない時間帯を指定して、実際にディスプレイを消灯する設定を追加する。初期は無効とし、時間帯を管理画面で設定できるようにする。
- 画面だけを消し、予約サーバーと通知送信は継続する設計にする。AC電源、Windowsのスリープ・ロックとの関係は実機で確認する。
- 表示中は簡易表示を基本にする。入浴中の予約がなければ次の2人と開始時刻、あればその人と終了予定・次の人と開始時刻を表示し、時計・QRを添える。簡易・詳細で同じカードと見出しを用い、拡大・縮小・移動を滑らかにつなぐ。タッチ後は詳細表示、初期設定では最後のタッチから1分で簡易表示に戻す。管理画面で1〜60分に変更、または詳細表示に固定できる。表示変更はソースで準備中。
- 簡易表示でも文字・時計・QRを同じ位置に固定し続けないようにする。配置変更は補助対策であり、保護効果を保証するものではない。
- 消灯時間帯の終了時にはWindowsへ点灯を要求する設計とする。PCのスリープ復帰やロック解除とは区別する。自動消灯・点灯は未実装で、キーボード・マウスなしの運用は実機確認が必要。
- ゆっくり動くグラデーションも補助案とするが、静止した文字やカードを残したままの背景アニメーションだけで保護できるとは扱わない。軽量な動作と読み取りやすさを優先する。
- 必要以上の実際のディスプレイ輝度を避け、未使用時間の消灯を優先する。ダッシュボードの暗い配色と、OS側の輝度設定を区別する。

配置や背景の変更は今後の設計案で、寿命を延ばす効果を検証済みという意味ではありません。これらのv2.0.0向け機能はv1.3.0には含めません。

## 確認したメーカー資料

- [Apple：Avoiding image persistence on Apple displays](https://support.apple.com/en-us/101373)。IPS液晶の残像と、未使用時の消灯・スクリーンセーバーを説明。2023年公開、現在はアーカイブ記事。
- [HP：TFT-LCD flat panel monitor image retention（PDF）](https://h10032.www1.hp.com/ctg/Manual/c01609330.pdf)。固定画像の長時間表示を避けること、表示画像の変更、未使用時の消灯を推奨。2006年の技術資料。

いずれも古い一般資料なので、特定の現行パネルの耐久時間や、現在の対策で何時間安全かを保証する根拠にはしません。
