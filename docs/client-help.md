# クライアントの使い方ガイド（v2.1.0向け開発中）

初回のパスワード設定が終わると、予約と事前希望のガイドを表示します。通常のログインや再読み込みでは再表示しません。メニューの「ヘルプ」からいつでも読み直せます。

持ち物とスタンプカードの見出し左側に「？」を設置します。基本操作を先に示し、細かな条件は「詳細を見る」に折り畳みます。自動予約は曜日別の表で確認し、曜日のプルダウンから1曜日ずつ編集します。予約する・入らない/様子見・未設定（無効）を選び、「設定する」で保存します。様子見を選ぶと説明を表示し、説明を閉じても未保存の選択は維持します。

## 説明の読み込み

`public/help.js` と `public/help/content.json` はガイドを開いたときだけ取得します。外部サイトからスクリプトや個人データを取り込むことはありません。外部の説明書を開かなくても基本ガイドと同じサーバー上の `/help/` を利用できます。予約データや家族のリンクはオンライン説明書へ送信しません。

説明文は `public/help/content.json` を編集し、`python packaging/build-help.py` で同一サーバー用の説明書を更新します。基本の文言・詳細をアプリとオンライン説明書で共通にします。サイトの組み立てにはPython標準ライブラリのみを使います。

## GitHub Pagesの公開

公開先は https://slfinside.github.io/bathjun/ です。説明書・スタイル・フォントだけを `gh-pages` ブランチへ置きます。サーバーのソース・データ・設定・共有URLは含めません。非公開リポジトリ本体の公開設定は変更しません。

```sh
python packaging/build-help.py --output /tmp/bathjun-help-site
```

GitHubのリポジトリ設定 → Pagesで「Deploy from a branch」、ブランチを `gh-pages`、フォルダーを `/ (root)` にして保存します。現在のGitHub連携はPages設定APIへのアクセスを403で拒否されるため、この初回設定はブラウザーで行う必要があります。非公開リポジトリでPagesを使えるかはGitHubのプランにも依存します。サイトは公開する前提の汎用説明だけで構成しています。

## 軽量化と確認範囲

- 書体は元のNoto Sans JPを維持します。WindowsダッシュボードのTTFは変更しません。
- 通常・太字とも元の16,732文字をすべて保持し、重複のない共通文字と追加の文字集合へ分割しました。共通文字の2ファイルは合計227,544バイトです。
- 文字集合の生成は `fonttools[woff]` を用い、`python packaging/build-web-fonts.py` で行います。名前などの個人データを参照せず、公開のUI文言から共通文字を決めます。生成済みファイルを同梱するので、利用者のPCにPythonを入れる必要はありません。
- 画面用ファイルはBrotli／gzipで圧縮し、ブラウザーがETagで更新確認します。長い家族用リンクの認証は304応答やフォント取得にも適用します。API応答と家族用の起動URLを含むmanifestは `no-store` を維持します。
- テスト用データによるChromiumの390px幅で通常画面のフォント取得量227,544バイトを確認。珍しい文字の追加取得、初回登録・再ログイン、各ヘルプ、折り畳み、未保存の設定維持と保存、320〜1200pxの説明書も確認しています。実機iPhoneの通信時間を保証する測定ではありません。

## 自動予約の統合と表示

以前の曜日予約はそのまま保持します。旧「毎日、自動で入らない/様子見」を利用していた場合は、予約設定のない曜日を様子見として表示します。新しいフォームで保存すると、表に表示された曜日ごとの指定が優先されます。既存の予約・希望や、決定済みの順番を設定保存だけで取り消したり変更したりしません。

曜日設定から入力された予定には、希望から確定した後も「自動予約」を表示します。通常の手入力の希望が自動確定したケースにはこの印を付けません。手入力で変更した場合は印を外します。旧データでは実行履歴のrevisionから判別できる分を引き継ぎます。
