# v2.0.0-rc4の使い方

この文書はv2.0.0-rc4に収録した機能を説明します。公開済みv1.3.0の配布物には含まれません。既存データベースには表・列を追加して移行し、メンバー・認証・予約を保持します。

## メンバー向け

右上の2本線ボタンからメニューを開きます。開いている間はボタンが×に変わります。未受取のプレゼントがある間は右上に小さな印が付きます。開くだけでは印は消えず、受取完了で消えます。

- ホーム：予約・スケジュールと、その週のスタンプの期間・達成状況。
- おふろを予約する：ホームへ戻り、順番が来ていれば予約、まだなら事前希望を入力。予約済みなら、変更できる予約を開きます。
- プレゼントボックス：アイテムを受け取ると持ち物へ加算。隣の「配布履歴」には自分宛てだけを表示します。
- 持ち物：アイテムをタップして説明と所持数を確認し、「使う」から対象の操作へ進めます。入力画面を開いただけでは消費しません。
- スタンプカード：前後の週とスタンプ獲得履歴を確認します。
- 設定：アイコン、パスキー、通知の種類・分数、自動の様子見、ログアウト。

予約と事前希望の入力は同じホーム上の操作枠へ統合しています。「みんなの希望」は独立した共有一覧です。

### スタンプと完了報告

日曜〜土曜の7枠を埋める週間カードです。土曜の夜〜日曜朝は土曜の枠です。

「入らない/様子見」はすぐには成功・失敗にせず「−」で保留します。初期設定では2日続けて入浴しないと、2日目の入浴時間帯の終了時に両日が失敗になります。次の日に期限内の入浴完了報告をすれば、前日の保留も成功になります。例えば土曜が様子見、日曜が入浴完了なら両日成功となり、土曜分で前週が達成した場合は、その時点で前週の特典が届きます。成功を補った様子見もお風呂スタンプで表示し、履歴では区別して記録します。

連続日数は管理者が1〜30日で変更できます。入力を取り消して予約した場合は、実際の完了報告で判定します。次の日が未入力・報告漏れで終了した場合も保留を成功にはしません。確定済みの判定は、後から設定日数を変えても変更しません。

予約開始後に「完了を報告」を押します。早く上がった場合も報告できます。受付期限は管理者がそれぞれ1〜180分で設定できます。初期値はダッシュボードでは予定終了から1分、クライアントでは3分です。報告済みは端末間で共有します。

7枠そろった時点で特典を自動抽選し、プレゼントボックスへ送ります。ホームを表示すると、サイト内のお祝いモーダルで抽選結果を表示します。確認済みのお祝いは同じ週に繰り返し表示しません。受取はプレゼントボックスから行います。

### アイテム機能が無効なとき

管理者がアイテム機能を無効にすると、予約・スケジュール・抽選結果からアイテムの表示を隠し、通知マーク・吹き出し・報酬の演出も出しません。プレゼントボックスと持ち物は確認用に残り、プレゼントボックスには「アイテム機能が無効に設定されています。」と表示します。受取・使用・管理者による配布は停止します。

既存の持ち物、未受取のプレゼント、確率UPの残回数は保持します。確率UPは無効中の抽選には適用せず、残回数も減りません。既に確定した予約の延長・ガードなどは保持します。未確定の希望はアイテムを消費せず通常の上限で自動確定を試みるため、上限を超える希望は時間を調整してください。無効中に達成した週の報酬は、再有効化後に本人がアクセスした際に届けます。

### チケット

| 種類 | 効果・消費 |
| --- | --- |
| 順番抜かし | 通常の順番を待たずに予約。重なるガードなしの予約は、開始済みでも希望へ戻します。確定時に1枚消費 |
| 時間延長 | その予約の上限を増やします。初期+30分。確定時に1枚消費 |
| 抽選確率UP | 以後の抽選3回分、1番になる確率を未使用の人の3倍にします。有効化で1枚消費。抽選しない日や固定順の日は回数を減らしません |
| 順番抜かしガード | 順番抜かしから予約を保護。希望時に指定でき、確定時に1枚消費。攻撃を受けなくても使用済み |

抽選の順番一覧では、その抽選に確率UPが適用された人に「確率UP使用」を表示します。適用状況は抽選時に記録するため、残回数が0になった後も表示が残ります。抽選後に使ったチケットは過去の結果に反映しません。スケジュールには表示しません。旧版で記録していない抽選には印を付けません。

券のアイコンはサイトに合わせた落ち着いた色のSVGです。確率UPは黄色に「↑UP↑」、順番抜かしは赤に追い抜きマーク、時間延長は緑に時計、ガードは青い盾で区別します。

1つの予約で使える予約用チケットは1種類です。チケットは無期限で持ち越せます。確率UPを追加使用しても倍率は3倍のままで、適用回数を追加します。

消費済みのチケットは、予約を取り消した場合や順番抜かしで希望へ戻された場合に払い戻しません。押し出された予約の時間延長効果は失われます。再度延長するには別のチケットが必要です。通常の上限を超えた希望は、短くするか新しい延長チケットを指定するまで確定しません。

順番抜かしを受けた本人には、元の予約時間と希望へ戻ったことを通知します。「設定 → 通知の種類」で個別にオン・オフを切り替えられます。通知の配信には従来どおり端末側の許可が必要です。

## 管理者向け

管理画面の「アイテム・特典」タブを使います。

1. 対象メンバーと内容をそれぞれチェックします。
2. 個数を入力して「配布」を押します。
3. 選んだ各メンバーのプレゼントボックスへ、選んだ各種類を指定枚数ずつ送ります。

同じタブに全員の持ち物、確率UPの残回数、配布日時・対象・内容・個数・受取状態を表示します。再読み込みボタンで最新状態を取得できます。

週間特典の枚数・出現比率、延長分数、確率UPの抽選回数も設定できます。初期は均等の出現比率、各1枚、ガードのみ2枚、延長30分、確率UP3回です。比率0のアイテムは抽選から外れます。延長分数は予約の刻み幅に合わせます。設定変更は以後の抽選・使用に反映し、既に確定した抽選結果・予約の延長分・有効化済みの残回数を変更しません。

### ダッシュボード

16:9〜3:2の横画面を基準にしています。簡易表示では入浴中／直後の報告対象と次の人、時刻、QRと縦方向のスケジュールを表示します。希望の重複は点線・別の列・模様で区別します。

タッチすると同じカードが滑らかに詳細表示へつながります。「ダッシュボード」タブで簡易表示へ戻る時間（初期1分、1〜60分）や詳細表示への固定を設定します。

「完了を報告」のタップは、簡易表示のままで使えます。報告を押しても詳細表示へ切り替わりません。予約終了後は1分間「入浴完了」と報告ボタンを残し、次の予約が始まっている場合もその人を併記します。

この変更には、別途計画中の起動入口の一本化・バックアップ等は含みません。

### チケットの使用制限

初期状態では、時間延長・順番抜かしともに開始まで120分以下の予約には使えません。時間延長は19:00〜23:00に少しでも重なる予約にも使えません。19:00ちょうどに終了、23:00ちょうどに開始する予約は重なりに含みません。

管理画面の「アイテム・特典」で、禁止時間帯のオン・オフと開始・終了、各チケットの直前制限の分数を変更できます。分数を0にすると直前制限を解除します。禁止時間帯は深夜をまたぐ指定も可能です。

希望の提出・自動確定・予約時刻の変更にも制限を適用します。希望を出せた時刻でも、順番が来た時点で開始までの時間が足りなければ自動確定しません。拒否時はチケットを消費しません。確定済み予約の時刻を変えずに備考だけ編集する場合は、制限で拒否しません。

公開済みRCで有効化した確率UPの残回数は、そのまま引き継ぎます。再起動や日付の経過では回数を減らしません。

### 達成報酬を固定する

「アイテム・特典」→「週間特典の設定」で、「ルーレットで決める」または「固定で渡す」を選びます。初期はルーレット方式です。

固定方式では種類を1つ選び、枚数を1〜99枚で指定して「特典設定を保存」を押します。7日達成すると、指定した種類と枚数をプレゼントボックスへ自動送付し、ホームでお祝い画面を表示します。抽選の演出は行いません。

変更は、以後に7日達成した報酬から反映されます。すでに決まった報酬は、未受取でも種類・枚数・表示方式を変えません。固定方式ではルーレットの枚数・出現比率の欄を無効にし、ルーレットへ戻すと以前の設定を再び使えます。

### ダッシュボードのアイコンとカウントダウン

プロフィールで選べる48種類の絵文字は、同梱画像で表示します。独自の絵文字を設定している場合はWindowsの絵文字フォントで表示します。ライセンスと出典は public/emoji/README.md にあります。

入浴終了まで・次の入浴開始までのカウントダウンは、60分以上なら「2時間15分」のように表示します。予約フォームなどの所要時間は、従来どおり「90分」などの分表記です。

### 自動消灯・自動点灯

管理画面の「ダッシュボード」で「時間帯で自動消灯・点灯する」をオンにし、「表示設定を保存」を押します。初期はオフ、時間帯の初期値は **08:00〜15:00、02:00〜04:00（日本時間）** です。時間帯は1〜8件まで追加・変更・削除でき、日をまたぐ指定や重なる指定にも対応します。

開始時刻に画面だけを消し、終了時刻には操作なしで点灯を要求します。重なる時間帯があれば、すべての消灯時間帯から外れてから点灯します。消灯中もサーバーと通知を継続するため、管理画面とサーバー自身で実行継続要求を保持します。実機のWindows・Wi-Fi・端末ポリシーによる通信停止までは保証できないため、消灯後の接続確認が必要です。ダッシュボードを開いていない間も動きます。

タッチ・マウス・キー操作があったときは1分間点灯し、操作がなくなってから再び消灯します。開始時刻の直前に操作していた場合も1分間待ちます。自動設定をオフにする、AC電源が外れる、サーバーが終了する場合は、この機能で消していた画面へ点灯を要求します。

設定はサーバーPCのデータフォルダー内の display-schedule.json に保存されます。AC接続・サーバー稼働中に動作します。画面の点灯はWindowsのロック解除やスリープからの復帰ではありません。Windowsのロックや組織の電源設定は変更しません。実機のパネル・電源制御は未検証のため、初回は自動点灯することを端末上で確認してください。

### 更新の確認とタッチ操作

Windows管理画面の「最新版を確認」から、公開後はダウンロード・検証・更新・再起動まで進めます。非公開の間は自動取得を利用できず、認証情報の設定も不要です。手動のインストーラー選択は引き続き使えます。詳しくは[管理者向けガイド](administrator-guide.md#管理画面から更新する)を参照してください。

更新時の `TrimEnd(Char)` の互換性エラーを修正し、配布用ビルドをMicrosoftの.NET Framework 4.7.2参照APIに固定しました。CIでは実際にMonoで作った配布用プログラムをWindows上で実行します。

管理画面の余白や設定項目は、スクロールバーを触らず上下のスワイプでも移動できます。メンバー表や一覧は内部をスクロールし、端まで来た場合は画面全体へ引き継ぎます。

### 順番が来ている人をつつく

予約の順番一覧で、今予約する番の人に「つつく」を表示します。別のメンバーが押すと、本人の有効な通知先へ予約を促すPushを送ります。本人単位で全端末共通の1時間制限を保存し、その間は灰色の「あと○分」で操作を無効にします。日付の切替やサーバー再起動でも制限を保ちます。

受け手は「設定」→「通知の種類」→「つつかれた」で無効にできます（初期有効）。予約済み・順番変更・受付終了・通知オフ・期限切れの送信待ちは破棄します。通知未設定の人にはボタンを無効表示します。

### 予約終了時の通知

予約の終了時刻になると「上がったら入浴完了を報告してください」と通知します。本人の「設定」→「通知の種類」で「予約終了時の完了報告のお知らせ」を切り替えられます（初期有効）。早上がりなどで報告済みなら送りません。変更・キャンセル・通知解除・ログアウトに追従し、再起動後は報告期限内に限り追送します。端末や回線による通知遅延は、報告期限を延長しません。

## rc4の追加機能

[日付・予約・スタンプの区切り](calendar-days.md)と[おふろスタンプ・インクの使い方](user-guide.md#おふろスタンプとスタンプのインク)を参照してください。プレゼントの説明は「説明を見る」から開けます。スタンプカードの成功は丸いお風呂スタンプ、失敗は黒いバツ、未確定はグレーのハイフンで表示します。
