# ふろじゅん v2.1.0-beta2

v2.1.0-beta1の次の2点を修正したベータ版です。

- **管理画面が開けず閉じる問題を修正。** お知らせの「画像があるか」を数値の0/1で送っていたため、Windowsの真偽値変換でエラーになっていました。false/trueへそろえ、既存のお知らせもそのまま読み込めます。データの削除・初期化は必要ありません。
- **お知らせを中央に表示。** スマホ用の下寄せ設定をお知らせには適用せず、スマホ・横画面・PC幅で上下左右の中央へ配置します。長い本文は枠の中でスクロールできます。

画像あり・なしのお知らせとメンバーを登録した状態で、Windowsのインストーラ版・ZIP版の管理画面を起動する確認を追加しました。時刻未定の希望・期限なしの入浴報告・「入っていない」からの取り直しはbeta1から引き継ぎます。

## ダウンロードと更新

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

**管理画面が開けない場合は、サーバーのコマンドプロンプトでCtrl+Cを押して停止してから、同じインストール先へ上書き更新してください。** 保存済みの予約・設定・お知らせは引き継ぎます。ZIP版は停止してから新しいZIPを別フォルダーへ展開し、そちらの「はじめる.cmd」を開きます。

安定版の自動更新では、このベータ版を取得しません。
