# ふろじゅん v2.1.0-beta3

beta2から、次の不具合を修正しました。

- **共有端末のログイン切り替え。** スタンプ選択画面の読み込み中にログイン先が変わっても、前の人の持ち物や選択候補を表示しません。
- **別端末からの予約・希望の変更。** 古い入力画面から取り消そうとしても、新しく変更された予約・希望は消しません。現在の予定を読み込み直すよう案内します。
- **日付が変わった入力画面。** 入力中に表示できる日付が変わった場合は画面を閉じ、開き直しを案内します。古い入力内容を別の日へ送信しません。

スタンプ選択画面は必要になったときに読み込み、初期画面の軽量さを維持しています。管理画面・お知らせの修正、時刻未定の希望、期限なしの入浴報告などはbeta2から引き継ぎます。

## ダウンロードと更新

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

サーバーを停止してから、同じインストール先へ上書き更新してください。管理画面が開けない場合はサーバーのコマンド画面でCtrl+Cを押して停止できます。予約・設定・お知らせは引き継ぎます。ZIP版は停止後に新しいZIPを別のフォルダーへ展開し、そちらの「はじめる.cmd」を開きます。

更新後、クライアントの予約画面も再読み込みしてください。安定版の自動更新では、このベータ版を取得しません。
