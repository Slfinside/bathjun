ふろきゅ～ v2.0.0-rc（再公開版）です。以下の変更をインストーラ版・ZIP版の両方へ収録しました。

以前のrc〜rc4を削除し、変更をまとめてrcとして公開し直します。既存データを保持して移行します。

## 今回の追加

- **未確定の日にもスタンプのインクを使用可能**。今週の今日までの「−」と「×」を選んで成功にできます。未来日・成功済み・過去週は対象外で、インク1個を消費し、スタンプ本体は残ります。
- **曜日ごとの自動予約**。本人の設定から、曜日ごとの開始時刻・長さ・備考を登録できます。自分の予約順が回ってきたらサーバーが一度だけ自動送信し、空いていれば確定、重なっていれば事前希望として残して結果を通知します。画面を開く必要はありません。既存入力を上書きせず、取り消した希望を自動で復活させません。アイテムは自動では使いません。

## 主な変更

- **日付と予約・スタンプの区切りを分離**。「今日」と抽選は日本時間0:00で切り替えます。入浴時間帯の設定を廃止し、予約・スタンプの所属日を決める区切り時刻（初期7:00）へ変更しました。朝に当日分の抽選・予約を準備しつつ、朝の入浴は前日分から確認できます。6:30〜7:30など区切りをまたぐ予約は開始時刻で所属日を決め、前後の日の予約とも重複を確認します。既存の時間帯・予約・希望を保持し、新方式は更新翌日分から適用します。
- **ダッシュボードを整理**。詳細スケジュールは右側に縦長で表示し、時間が下へ進みます。簡易・詳細のメンバー一覧を削除し、次の予約がない場合の文言の見切れを改善しました。予約画面と同じ日本語フォントを維持し、文字描画をClearTypeへ変更しました。
- **実消灯の処理を修正**。予約サーバー自身でもWindowsの実行継続要求を保持し、管理画面・サーバー双方の保護を確認して消灯します。手動・自動消灯の干渉を修正し、入力や設定時間帯の終了で点灯を要求します。黒画面方式への置き換えや、Windowsの電源プラン・組織ポリシーの変更は行いません。実機での通信継続は下記の確認が必要です。
- **スタンプカードをスタンプらしい表示へ**。成功は湯気と浴槽の丸いお風呂スタンプ、失敗は黒いバツ、未確定はグレーのハイフンで表示します。
- **おふろスタンプ・スタンプのインクを追加**。持ち物から今週の今日までの未確定・失敗の日を選び、インク1個で成功へ変更できます。木製のおふろスタンプ本体は消費せず、インクがないと「使う」は無効です。予約・入浴完了報告は変更せず、7日そろえば週間報酬を一度だけ届けます。初期はスタンプ本体は報酬に出現せず、インクは既存4種類と同じ当選確率で1個。管理画面から本体・インクの配布、固定報酬・出現比率の設定もできます。
- **プレゼントの説明を折り畳み表示**。プレゼントボックス・配布履歴で必要なものだけ「説明を見る」から開けます。持ち物と同じ説明・設定に応じた使用制限を表示し、更新中も開いている説明を保持します。

## ダウンロード・更新

- `Bathjun-Setup-x64.exe`：インストール版。サーバーを終了し、これまでと同じインストール先へ上書きしてください。
- `Bathjun-Portable-x64.zip`：インストール不要のローカル試用版。サーバーを終了し、新しいフォルダーへ展開して起動できます。
- 両ファイルの `.sha256` を添付。GitHubのSource code ZIP / tar.gzは実行用ZIPとは別です。

旧rc2〜rc4からは版番号比較で更新対象に出ない場合があるため、GitHubから取得したインストーラを手動で実行して上書きしてください。

更新前にサーバーを終了してデータフォルダー（通常版 `%LOCALAPPDATA%\BathjunData`、ZIP版 `%LOCALAPPDATA%\BathjunTestData`）をバックアップしてください。既存のメンバー・認証・予約・持ち物を保持して移行します。更新後は予約画面を再読み込みしてください。外部公開は引き続き「固定URLで外部公開」から起動します。非公開リポジトリでは自動取得できないため、GitHubへログインしてインストーラを取得してください。
