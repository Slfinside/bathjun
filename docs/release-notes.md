# ふろじゅん v2.1.0-beta1

v2.0.2を含む、v2.1.0の最初のベータ版です。

## 時刻を決めず、入浴時間だけ共有

予約・希望の入力で「時刻は決めない」を選ぶと、所要時間と備考だけを共有できます。開始時刻や予約枠は確保しません。後から開始時刻を決め、通常の予約順・重複確認に従って確定します。

全員の予約・希望・様子見が出そろうか、「これから必要な時間 × 1.2 ＋ 1時間」が夜の残り時間を上回ると、時刻未定の本人に開始時刻の入力を促します。夜の締め切りは初期で翌2:00、管理画面で変更できます。翌朝の予定や入浴済みの分を計算から除き、入浴中は残り時間を数えます。

[通知条件・計算例](https://github.com/Slfinside/bathjun/blob/main/docs/duration-only-wishes.md)

## 入浴報告と取り直し

- 完了報告の期限をなくしました。予約開始後なら、後日でも報告できます。本人の画面からの完了報告は既存の管理者設定に従います。
- 両方のスケジュールに「完了」、または斜線付きの「入っていない」を表示します。「入っていない」は確認を挟んで記録します。
- 「入っていない」とした場合、その日分の受付中なら取り直せます。元の予約は斜線付きで残し、空いた枠は他の人も使えます。
- ダッシュボードの大きな報告ボタンは設定時間まで表示。その後もスケジュールをタッチして報告できます。クライアントの「入浴の報告」、ダッシュボードの「未報告 ○件」から過去の未報告予約も開けます。
- 未報告のスタンプは、その日分の終了時刻（初期は翌7:00）で失敗にします。後日の有効な完了報告は成功へ反映します。報酬やインクを二重には配布しません。

[入浴報告・取り直しの使い方](https://github.com/Slfinside/bathjun/blob/main/docs/bath-reports.md)

## 配布物と更新

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

安定版の自動更新ではベータ版を取得しません。ベータ版を試す場合は、サーバーを停止してから手動で上書きインストールしてください。更新前にデータフォルダーをバックアップしておくと、元の版へ戻すときにも使えます。保存先の予約・設定は引き継ぎます。

v2.0.2の管理画面表示、異常終了時の復元、起動時のバージョン表示も含みます。更新時には今回の新機能のお知らせを一度だけ配信し、プッシュ通知は送りません。
