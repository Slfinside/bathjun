毎日自動で「入らない/様子見」にする個人設定を追加し、希望の自動確定を予約順に対応させました。

- 本人の「ログイン・通知の設定 → 毎日の予約設定」で自動の様子見を選べます。初期オフで、次に順番を決める夜から末尾へ回ります。予約・希望・前夜分は自動で取り消しません。その夜だけ通常順へ戻すこともできます。
- 管理画面の「設定 → 下位の人の希望と重なっても自動確定する」で優先ルールを切り替えられます。初期オンで、保存後すぐに当日分も再判定します。
- 18:00〜18:30と18:30〜19:00のような境界の一致は許容します。確定済みの予約との実際の重複は常に拒否します。

インストール版は `Bathjun-Setup-x64.exe`、このPC内のテスト用は `Bathjun-Portable-x64.zip`。管理画面で取得済みインストーラーを選んで更新するか、サーバーを停止して上書き実行してください。予約画面は更新後に再読み込みしてください。外部公開は引き続き「固定URLで外部公開」から起動します。

日中・深夜の自動消灯、起動アプリの一本化、連続入浴の特典などはv2.0.0の予定で、この版には含めません。LCDの表示保護に関する調査は docs/display-protection.md にまとめています。
