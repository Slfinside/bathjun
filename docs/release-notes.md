## 今回の変更

- 日曜〜土曜の週間スタンプカードと完了報告。ダッシュボードは予約終了から1分、クライアントは3分以内。早上がりの報告にも対応します。
- 7日達成で特典を自動抽選し、プレゼントボックスへ送付。ホームではサイト内のお祝いモーダル、専用画面では獲得履歴と前の週を確認できます。
- 順番抜かし・時間延長・抽選確率UP・ガード。期限なしで持ち越せ、1予約につき1種類を使えます。順番抜かしで予約が希望へ戻った本人には専用通知を送ります。
- 持ち物・プレゼント受取・本人宛ての配布履歴・スタンプカード・設定を右上メニューに整理。事前希望の操作を予約の操作枠へ統合しました。
- 管理画面にメンバー別の持ち物一覧と、対象・種類・個数を指定する配布機能、特典設定を追加しました。
- 横画面のダッシュボードを改修。残り時間、次の予約、共有QR、縦スケジュールを表示し、簡易表示のまま完了報告できます。簡易・詳細を同じカードのアニメーションで切り替えます。
- 予約・希望の重複表示、種類別のSVGチケット／盾アイコン、未受取プレゼントの通知マークを追加しました。

## 取得・更新

- `Bathjun-Setup-x64.exe`：インストール版。既存サーバーを停止して上書きインストール、または管理画面から取得したインストーラを選んで更新してください。
- `Bathjun-Portable-x64.zip`：管理者権限を使わない、このPC内のテスト用ZIP版。
- 両ファイルの `.sha256` も添付しています。Source codeは実行用ZIPではありません。

既存のメンバー・認証・予約は保持し、データベースへ表と列を追加します。予約画面は更新後に再読み込みしてください。外部公開は従来どおり「固定URLで外部公開」から起動します。

使い方は同梱の `docs/v2-preview-guide.md` を参照してください。このリリースはPre-release扱いで、安定版のlatestリンクは変更しません。
