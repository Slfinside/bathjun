## v1.3.0からの主な変更

- **週間スタンプカードと達成報酬**：日曜〜土曜の7日間を管理し、入浴完了を報告するとお風呂スタンプを押します。成功はお風呂マーク、失敗は黒いバツ、未確定はグレーのハイフンです。様子見は初期2日連続で入浴時間が終わるまで保留し、翌日の入浴で保留分を成功にする仕組みも追加しました。7日そろうとルーレットまたは固定の報酬が一度だけプレゼントへ届き、ホームにお祝いを表示します。
- **アイテム・プレゼント・持ち物**：順番抜かし、時間延長（初期30分）、抽選確率UP（初期3回・1番の重み3倍）、ガードを追加。管理者が対象・種類・個数を選んで配布でき、本人はプレゼントボックスで受け取ります。持ち物・本人宛ての配布履歴・折り畳み説明も追加しました。使用制限・出現比率・固定報酬・機能全体のオンオフを設定できます。
- **おふろスタンプとインク**：今週・先週の、今日までの「−」「×」をインク1個で成功にできます。木製スタンプ本体は残ります。持ち物だけでなく、ホームとスタンプカードからも直接使えます。初期報酬はスタンプ本体の出現比率0、インクは既存4種類と同率で1個です。未来日・成功済み・先々週以前は対象外。先週分で7日そろった場合も報酬を受け取れます。
- **自動予約・事前の様子見・希望の確定**：本人が曜日ごとの開始時刻・長さ・備考を設定すると、自分の予約順で一度だけ自動送信します。空いていれば確定し、重なれば希望として残して通常の結果通知を送ります。「入らない/様子見」は明日・明後日にも事前共有できます。抽選済みの日の希望は、順番待ちでも開始時刻に予約・ほかの希望と重ならなければ確定するようにしました。境界の時刻が一致する予約は許容し、チケットの制限は維持します。
- **日付・画面・通知**：「今日」と抽選は日本時間0:00で切り替え、予約・スタンプの所属日は開始時刻と区切り（初期7:00）で決めます。朝の入浴は前日分から確認しながら当日分を準備できます。クライアントメニューを整理し、予約順の「つつく」（受け手ごと1時間に1回）、順番抜かしの通知、予約終了時の完了報告通知を追加。本人画面・ダッシュボードの報告期限を個別設定できます。
- **Windowsダッシュボードと管理画面**：現在・次の人、残り時間、時計、QR、縦方向のスケジュールを表示。簡易・詳細をアニメーションで切り替え、簡易表示からも完了報告できます。希望の重複、絵文字、時間・分表記、同梱日本語フォントとClearType描画に対応。管理画面のタッチスクロールと更新時の互換性エラーも修正しました。
- **消灯・更新・配布・セキュリティ**：手動・時間帯による実消灯／点灯の要求を追加し、予約サーバー自身でもWindowsの実行継続要求を保持します。更新パッケージの検証・ZIP更新失敗時の復元に対応し、不正URLでサーバーが停止する問題を修正しました。日本語名は「ふろきゅ～」へ変更し、bathjunの識別子・保存先・認証・バージョン系列は維持します。

## ダウンロード・更新

- `Bathjun-Setup-x64.exe`：インストール版。サーバーを終了し、同じインストール先へ上書きしてください。
- `Bathjun-Portable-x64.zip`：インストール不要のローカル試用版。サーバーを終了し、新しいフォルダーへ展開してください。
- 両方に `.sha256` を添付しています。GitHubのSource code ZIP / tar.gzは実行用ZIPとは別です。

更新前にデータフォルダー（通常版 `%LOCALAPPDATA%\BathjunData`、ZIP版 `%LOCALAPPDATA%\BathjunTestData`）をバックアップしてください。メンバー・認証・予約・持ち物を保持して移行します。既存の入浴時間帯は保持し、新しい日付の区切りは更新翌日分から適用します。更新後は予約画面を再読み込みしてください。

旧RCは削除し、beta1として公開しています。旧RCからは版番号や更新機能の対応範囲が異なるため、GitHubから取得したインストーラを手動で実行して上書きしてください。非公開リポジトリでは取得にGitHubへのログインが必要です。外部公開は引き続き「固定URLで外部公開」から起動します。

[利用者向け](https://github.com/Slfinside/bathjun/blob/v2.0.0-beta1/docs/user-guide.md)・[管理者向け](https://github.com/Slfinside/bathjun/blob/v2.0.0-beta1/docs/administrator-guide.md)・[v1.3.0からのソース差分](https://github.com/Slfinside/bathjun/compare/v1.3.0...v2.0.0-beta1)を確認できます。Pre-release扱いで、安定版のlatestリンクは変更しません。

## 検証・確認できていない点

Nodeテスト184件、スマホ幅を含むブラウザー操作、Windowsでの描画・設定・更新判定、インストーラ・ZIPのビルド・同梱内容・ハッシュ・個人データ混入を検証しています。

**消灯後の動作はWindows設定も確認してください。** スリープを「なし」にしていても、消灯中はiPhoneからHTTPSへ接続できず、ロック解除後に接続できる端末の報告があります。実消灯は維持していますが、復帰後のロック画面はWindows Helloの「サインインを再度求めるタイミング」が原因と報告者が確認しました。消灯中に別端末からERR_TIMED_OUTになる報告が残っており、本体・Funnel・OSのどこで止まるかは未特定です。[確認手順](https://github.com/Slfinside/bathjun/blob/v2.0.0-beta1/docs/administrator-guide.md#実消灯後にロック解除が必要https接続が止まる場合)と[調査記録](https://github.com/Slfinside/bathjun/blob/v2.0.0-beta1/docs/screen-off-investigation.md)を参照してください。アプリからWindowsのセキュリティ・電源ポリシーは変更しません。

実機iPhoneのPush到達・実機タッチ・パネルの消灯／点灯は未検証です。インストーラは未署名です。起動入口の一本化、自動バックアップ・復元、端末単位のログイン管理、更新署名の強化は未搭載です。
