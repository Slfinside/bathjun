# ふろじゅん v2.0.2

v2.0.1で管理画面が表示される前に終了してしまう問題への対策と、起動時のバージョン表示を追加しました。

- 管理画面が異常終了しても予約サーバーは動かし続け、一度だけ管理画面を自動で開き直します。起動用ショートカットから再表示することもできます。
- 更新時のお知らせデータが読み込めなくても、管理画面と予約サーバーの起動を続けます。上書きインストール時には、古い更新マーカーを取り除きます。
- コマンドプロンプトに **ふろじゅん v2.0.2** を表示します。管理画面側のエラーも出力し、インストール直後の起動に失敗した場合も画面がすぐ閉じないようにしました。
- インストーラ版・ZIP版に同じ修正を適用。実際の配布物をWindowsで起動し、管理画面・予約ページへの接続・正常終了を確認するテストを追加しています。

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

更新する場合はふろじゅんを停止してから、今のインストール先へ最新版のインストーラを実行してください。予約データ・設定の保存先は変わりません。v2.0.1が起動しない場合も、管理画面を使わずに上書き更新できます。

v2.1.0向けに開発中の、時刻未定の希望・期限なしの完了報告は、この版には含まれません。
