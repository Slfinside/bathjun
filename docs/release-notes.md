# ふろじゅん v2.1.0-beta4

beta3以降の追加機能、スマホ表示、入力・報告操作の修正をまとめたベータ版です。

## 入浴の記録と報告

- **予約外の入浴を共有。** メニューの「入浴の報告」から、実際に入った時刻・上がった時刻・備考を記録できます。家族のスケジュールに「予約外・入浴済み」と表示し、スタンプも成功になります。既存の予約・希望・順番は変更しません。クライアントからの報告は管理者が有効にした場合に利用できます。
- **完了報告はその日分の受付中に。** クライアントからの完了報告は、初期設定では翌7:00までです。6:30〜7:30のように区切りをまたぐ予約は、その予約の終了まで受け付けます。後日の報告・訂正はサーバーのダッシュボードから行えます。
- **二重処理を防止。** 同じ予約外の報告を再送しても記録・スタンプ・週間報酬・対象のインク返却を重複させません。予約外で入った記録と、すでにある予約への完了報告は別に扱います。

## 表示と操作の修正

- スマホで予約・報告・確認・プロフィール・ヘルプ・アイテムなどのウインドウが左下に寄る共通設定を修正。中央へ配置し、長い内容は枠内でスクロールします。
- 未保存の通知設定を、自動更新や通知許可操作による再描画でも保持します。入力からフォーカスを外した場合も設定が戻りません。
- ガイドの読み込み中にログアウトや画面移動をした場合、古いガイドを後から開きません。
- 完了報告の送信中はボタンを無効にし、未入浴報告への切り替えや重複操作を防ぎます。
- 入浴報告を報告待ち・過去の未報告・予約外の記録に整理。設定・ログイン・ヘルプの文言、ボタン、見出し、余白も揃えました。補助画面は必要時に読み込みます。

beta3までの管理画面の起動・復元、お知らせの表示、パスキー・共有端末の認証、古い画面からの取り消し防止、時刻未定の希望なども含みます。

## 確認範囲

自動テスト、スマホ幅・横画面・PC幅のブラウザー操作、予約・アイテム・予約外の入浴を組み合わせた操作を確認します。Windowsでは管理画面・ダッシュボードの表示、インストーラ版・ZIP版の起動、更新時のデータ引き継ぎを検証します。

ブラウザーでの確認はChromiumによるものです。iPhoneのSafari実機、実際の生体認証・プッシュ配信、実機の消灯・自動点灯は今回の自動検証に含みません。

## ダウンロードと更新

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

サーバーを停止してから、同じインストール先へ上書き更新してください。管理画面が開けない場合はサーバーのコマンド画面でCtrl+Cを押して停止できます。予約・設定・お知らせは引き継ぎます。ZIP版は停止後に新しいZIPを別のフォルダーへ展開し、そちらの「はじめる.cmd」を開きます。

更新後、クライアントの予約画面も再読み込みしてください。安定版の自動更新では、このベータ版を取得しません。
