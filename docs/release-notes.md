朝は前夜の予約を確認しつつ、その日の午後の分を準備できるようにしました。日付切り替えは入浴時間帯とは独立した設定で、初期2:00です。

- 昨日・今日・明日・明後日の夜を表示。未来の日にも抽選前から希望を出せます。先行抽選は追加せず、当日分だけ抽選できます。
- 希望・予約のボタンを抽選ボタンと同じ大きな形に変更。
- 「希望が確定した」「確定できなかった」「予約する番」「入浴前」の4種類の通知を本人が個別に有効・無効にできます。
- 入浴前通知は本人が1〜180分前から設定。初期10分前です。

インストール版は `Bathjun-Setup-x64.exe`、このPC内のテスト用は `Bathjun-Portable-x64.zip` です。v1.1.1以降は管理画面から取得済みインストーラーを選んで更新できます。手動更新はサーバーを停止してから上書き実行してください。既存データは保持します。更新後、予約画面を再読み込みしてください。

7日連続の自己申告に対する上限延長・再抽選・追い抜かしの特典は、v2.0.0の検討中の案です。この版には含めません。
