サーバー用の常時表示ダッシュボードを追加しました。次に入る人、現在の人、予定、メンバーの状態、日本時間の時計、家族用リンクのQRを表示します。表示中の自動消灯を抑え、表示位置を動かします。

対応するWindows人感センサーを使う設定は初期状態で無効です。在席時は詳しく明るい表示、不在時は次の人と開始時刻の大きな表示になります。Windows Helloカメラだけでは利用できません。

- **通常導入**: `Bathjun-Setup-x64.exe`
- **このPC内だけで試す**: `Bathjun-Portable-x64.zip` を展開して「はじめる.cmd」
- **ソース**: GitHubの「Source code」。実行用ZIPとは別です。

更新前は管理画面の「サーバーを停止して終了」で終了してください。インストール版の既存データとTailscale設定は維持します。ZIP版のテストデータは通常版と別の場所に保存します。

使い方はREADMEから利用者用・管理者用ガイドへ進めます。Windows 10/11 x64・.NET Framework 4.7.2以降。本体とNode.jsを同梱し、配布ファイルは未署名です。

検証: Nodeの自動テスト、Monoでのネイティブ描画・入力・通信テスト、両配布物のファイル照合・DPI設定・チェックサム確認。Windows実機での消灯抑止と人感センサーは未検証です。
