# ふろじゅん v2.1.0

v2.0.2以降の追加機能と修正をまとめた正式版です。beta4の機能・画面構成を引き継いでいます。

## 時刻を決めずに所要時間を共有

予約・事前希望で「時刻は決めない」を選ぶと、おふろに使う長さだけを共有できます。開始時刻を決めるまでは予約は確定しません。

全員の入力がそろうか、夜の残り時間が少なくなった際に、時刻未定の希望を出している本人だけへ通知します。夜の締め切りは管理画面で変更でき、初期設定は翌2:00です。翌朝の予定や、入浴済みの時間は計算から除きます。[条件と計算例](https://github.com/Slfinside/bathjun/blob/main/docs/duration-only-wishes.md)を参照してください。

## 入浴の報告と予約の取り直し

- 完了した予約は「完了」、入っていない予約は斜線付きで表示します。「入っていない」の確定には確認を挟み、その日分の受付中なら予約を取り直せます。元の予約は記録として残ります。
- メニューの「入浴の報告」では、予約せずに入った時刻と備考も記録できます。家族のスケジュールに「予約外・入浴済み」と共有し、スタンプも成功になります。既存の予約・希望・順番は変えません。
- 本人の画面から入浴を報告するには、管理者による許可が必要です。初期は無効です。完了報告の受付はその日分の終了（初期は翌7:00）までで、区切りをまたぐ予約は予約終了まで受け付けます。後日の報告・訂正はダッシュボードから行えます。
- ダッシュボードの大きな報告ボタンが消えた後も、スケジュールや未報告の一覧から報告できます。未報告のスタンプは日が終わると失敗になり、後日の有効な報告を反映します。同じ報告の再送で記録・週間報酬・対象のインク返却を重複させません。

[入浴報告と取り直しの詳しい使い方](https://github.com/Slfinside/bathjun/blob/main/docs/bath-reports.md)も確認できます。

## 表示・入力・起動の修正

- スマホで予約・報告・確認・プロフィール・ヘルプ・アイテムなどのウインドウが左下へ寄る問題を修正。中央に配置し、長い内容は枠内でスクロールします。
- 未保存の通知設定や自動予約の入力を再描画でも保持します。ガイドの読み込み中にログアウトや画面移動をした場合、古いガイドを後から開きません。
- 別端末で変更された予約・希望を古い入力画面から取り消さないようにし、表示日が変わった入力画面から別の日へ予約を送ることも防ぎます。共有端末のアカウント切り替え中に、前の人のスタンプ選択画面を表示しません。
- ログイン・設定・ヘルプの文言、入浴報告のボタンや見出しを整理。補助画面は必要時に読み込み、初期画面の圧縮サイズ上限を維持しています。
- お知らせの画像情報によってWindows管理画面が閉じる問題を修正。管理画面の表示・再表示、起動時のバージョン表示など、v2.0.2までの対策も引き継ぎます。

## 確認範囲

公開前に自動テスト、スマホ幅・横画面・PC幅のブラウザー操作、予約・アイテム・入浴報告の混合操作を実行します。Windowsでは管理画面・ダッシュボード、インストーラ版・ZIP版の実際の起動・再表示、上書き更新、同梱お知らせの配信を検証します。v2.0.2とbeta4から正式版への更新選択も確認します。

ブラウザーでの自動確認はChromiumによるものです。iPhoneのSafari実機、実際の生体認証・プッシュ配信、実機の消灯・自動点灯は今回の自動検証に含みません。

## ダウンロードと更新

`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。

手動更新ではサーバーを停止してから、同じインストール先へ上書きしてください。管理画面が開けない場合は、コマンド画面でCtrl+Cを押して停止できます。予約・設定・お知らせ・家族用リンクは引き継ぎます。ZIP版は停止後に新しいZIPを別フォルダーへ展開し、そちらの「はじめる.cmd」を開きます。

この正式版は安定版の自動更新対象です。更新を有効にしている場合は設定時刻（初期は毎朝4:00、日本時間）に確認し、入浴中などを避けて適用します。

更新後はスマホ側の予約画面も再読み込みしてください。
