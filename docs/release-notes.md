## rc2からの変更

- **アイテム機能のオン・オフ**を管理画面へ追加。無効時は予約・スケジュール・抽選結果からアイテム表示を隠し、通知マークや報酬演出も出しません。プレゼントボックスと持ち物は確認用に残り、ボックスへ「アイテム機能が無効に設定されています。」と表示します。使用・受取・配布・確率UP適用は停止し、所持数・未受取分・残回数は保持。確定済みの予約の効果は維持します。
- **様子見のスタンプを保留**する仕組みを追加。初期は2日連続で入らないと、2日目の入浴時間帯が終了した時点で両日が失敗になります。それまでは「−」です。次の日に入浴を完了し期限内に報告すれば、前日の保留も成功になります。例えば土曜が様子見、日曜が入浴完了なら両日成功となり、前週の7枠がそろえば日曜の報告時点で前週の報酬が届きます。
- 判定日数は1〜30日で設定でき、手動・自動の様子見に適用。閾値に達する入力にはページ内の警告を表示します。確定した結果は再起動・設定変更後も保持し、報酬は重複発行しません。
- **完了報告の期限を設定可能**に。クライアント・ダッシュボード別に1〜180分、初期3分・1分。報告ボタン、ダッシュボードの前夜の継続表示、サーバーの受付判定に反映します。
- **予約終了時の完了報告通知**を追加。「上がったら入浴完了を報告してください」と送り、本人の設定でオン・オフを切り替えられます。報告済み・キャンセル・ログアウト・期限切れでは送らず、予約変更・再起動・再試行に対応します。

アイテム無効中に達成した週の報酬は、再有効化後に本人がアクセスした際に届けます。既存の延長付き希望は無効中には通常の時間上限で扱うため、必要なら時間を調整してください。

## 取得・更新

- `Bathjun-Setup-x64.exe`：インストール版。サーバーを終了し、これまでと同じインストール先へ上書きしてください。
- `Bathjun-Portable-x64.zip`：このPC内で試すZIP版。サーバーを終了し、新しいフォルダーへ展開して起動できます。
- 両ファイルの `.sha256` を添付。GitHubのSource code ZIP / tar.gzは実行用ZIPとは別です。

メンバー・認証・予約・持ち物を保持し、必要な表・列を追加します。更新前にサーバーを終了してデータフォルダー（通常版 `%LOCALAPPDATA%\BathjunData`、ZIP版 `%LOCALAPPDATA%\BathjunTestData`）をバックアップしてください。更新後は予約画面を再読み込みします。外部公開は引き続き「固定URLで外部公開」から起動します。

初回RC以前の更新画面には不具合があるため、適用できない場合はGitHubからインストーラを直接取得して実行してください。非公開リポジトリでは自動取得できません。
