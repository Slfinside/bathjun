# ふろじゅん v2.0.1

v2.0.0からの変更です。予約・メンバー・パスキー・所持アイテムなどのデータを引き継ぎます。

- **サーバーの自動更新：** 初期は毎朝4:00（日本時間）に確認し、公開された新しい安定版を取得・検証して更新、再起動します。入浴中・開始直前・保存中は見送ります。更新中もスリープ防止を引き継ぎ、再起動を確認します。有効・無効と時刻は管理画面で変更できます。非公開リポジトリの間は自動取得できません。
- **画面内のお知らせ：** 管理画面からタイトル・画像1枚・本文を各ページに入力し、最大10ページのお知らせを即時配信または予約配信できます。プッシュ通知は送りません。
- **更新後のお知らせ表示：** ページ数・次へ・スキップ・角丸画像を備えたダイアログで、メンバーごとに初回表示します。更新起動と配信履歴を照合して二重配信を防ぎます。今回は架空の画面とアイテム画像を使った3ページのテスト用お知らせを同梱しています。
- **インク返却：** 今日の未確定「−」へインクを使ったあと、同じ日分の有効な完了報告をすると、プレゼントボックスへインク1個を返却します。

インストーラ版とZIP版を同じソースから作成します。`Bathjun-Setup-x64.exe` がインストーラ、`Bathjun-Portable-x64.zip` がローカル専用ZIPです。`.sha256` はチェックサム、Source codeは開発用です。インストーラは未署名です。

[詳しい使い方](https://github.com/Slfinside/bathjun/blob/main/docs/updates-and-announcements.md)

時刻未定の希望と夜の計画通知は、今回には含めずv2.1.0向けに開発を継続します。
