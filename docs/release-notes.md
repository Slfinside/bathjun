# ふろじゅん v2.1.2

- iPhoneで、予約・事前希望の時刻欄が右にはみ出す問題を修正しました。
- 開始時刻は予約・事前希望・曜日ごとの自動予約ともに1分単位で選べます。所要時間が15分刻みの設定なら、たとえば19:07から30分を選ぶと19:37に終了します。管理画面の日付の区切りも1分単位で設定できます。
- 曜日ごとの自動予約が過ぎた時刻などで見送られた場合でも、その日の設定を有効な時刻に直せば、自分の番で再試行します。

Windowsにインストールする場合は `Bathjun-Setup-x64.exe`、同じPC内だけで試す場合は `Bathjun-Portable-x64.zip` を使ってください。更新の手順は[管理者向けガイド](https://github.com/Slfinside/bathjun/blob/main/docs/administrator-guide.md)を確認してください。
