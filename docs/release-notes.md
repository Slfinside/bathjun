ふろきゅ～ v2.0.0-rc2（第2リリース候補）です。初回RC以降の変更と修正を、インストーラ版・ZIP版の両方に収録しています。日本語名を「ふろじゅん」から「ふろきゅ～」へ変更し、bathjunの識別子・データ保存先・バージョン系列は引き継ぎます。

## 初回RCからの変更

- 延長・順番抜かしチケットの使用制限を追加。初期設定は予約開始まで120分以下の使用を禁止し、延長は19:00〜23:00に重なる予約も禁止。管理画面で変更できます。
- 週間スタンプの達成報酬に、ルーレットに加えて種類・個数を固定する設定を追加。抽選確率UPは初期3回の抽選分で、使用した人を抽選結果に表示します。
- 予約する番の人を「つつく」通知を追加。受け手ごとに全端末共通で1時間に1回まで。通知の有効・無効も本人が設定できます。
- 未受取のプレゼントがあるとメニュー下に吹き出しを表示。日付選択を日付の下へ移して幅を調整し、メニューとの干渉を防止しました。
- ダッシュボードの絵文字を同梱画像で表示し、残り時間は「2時間15分」のように表示。予約時間の入力は従来どおり分単位です。スタンプカードやダッシュボードの文字配置・説明を調整しました。
- 時間帯による自動消灯・点灯を追加。初期オフ、時間帯の初期値は08:00〜15:00・02:00〜04:00。複数時間帯・日跨ぎに対応し、管理画面で変更できます。
- Windowsの更新確認で発生した `TrimEnd(Char)` の例外を修正。.NET Framework 4.7.2の参照APIに合わせてビルドし、実際の配布用バイナリをWindowsでも検証します。
- 公開配布時の更新確認→ダウンロード→SHA-256・バージョン検証→更新・再起動に対応。ZIP版は内部検証と入れ替え失敗時の復元も行います。非公開リポジトリでは自動取得できず、GitHubのリリースページへ案内します。
- 管理画面の余白や項目上のスワイプでスクロールできるようにしました。
- 認証前の不正URLでサーバーが停止する問題を修正。APIの予期しない例外も捕捉します。[セキュリティ確認結果](https://github.com/Slfinside/bathjun/blob/v2.0.0-rc2/docs/security-review.md)に確認範囲と残る改善候補をまとめています。

## v2系列の機能

日曜〜土曜の週間スタンプ、入浴完了の自己申告、達成報酬、順番抜かし・時間延長・抽選確率UP・ガード、持ち物・プレゼント・本人宛ての配布履歴、新メニュー、管理者によるアイテム配布、簡易・詳細を切り替えられるダッシュボードを搭載しています。

## 取得・更新

- `Bathjun-Setup-x64.exe`：インストール版。既存サーバーを終了し、これまでと同じインストール先へ上書きしてください。
- 初回RC以前の管理画面は、更新確認の不具合や旧製品名の検証によりrc2を適用できない場合があります。その場合はGitHubからインストーラを取得して直接実行してください。
- `Bathjun-Portable-x64.zip`：管理者権限を使わない、このPC内のテスト用ZIP版。既存サーバーを終了して、新しいフォルダーへ展開して起動できます。
- 両ファイルの `.sha256` を添付しています。GitHubのSource code ZIP / tar.gzは実行用ZIPとは別です。

既存のメンバー・認証・予約は保持し、必要な表・列をデータベースへ追加します。更新前にサーバーを終了し、データフォルダー（インストール版は `%LOCALAPPDATA%\BathjunData`、ZIP版は `%LOCALAPPDATA%\BathjunTestData`）をバックアップしてください。更新後は予約画面を再読み込みします。外部公開は引き続き「固定URLで外部公開」から起動します。

[利用者向け](https://github.com/Slfinside/bathjun/blob/v2.0.0-rc2/docs/user-guide.md)・[管理者向け](https://github.com/Slfinside/bathjun/blob/v2.0.0-rc2/docs/administrator-guide.md)・[v2新機能](https://github.com/Slfinside/bathjun/blob/v2.0.0-rc2/docs/v2-preview-guide.md)の使い方を用意しています。Pre-release扱いで、安定版のlatestリンクは変更しません。
