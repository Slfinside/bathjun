# ふろじゅん v2.1.1

- 予約の開始時刻を、iPhoneやWindowsなどのOS・ブラウザー標準の時刻入力で選べるようにしました。所要時間も標準の選択欄から選べます。新規設定は5分刻みで、既存の刻み幅は引き継ぎます。
- 予約やお知らせなどのウインドウに下へ続く内容があるとき、下端に約80pxのフェードを表示します。最後までスクロールすると消えます。
- ボタン・入力欄・説明文を調整し、予約と希望が重なる場合の詳細を折り畳みました。Windowsの管理画面やダッシュボードの表示も調整しました。
- ホームの日付表示の右側に再読み込みボタンを追加しました。
- iOSのホーム画面アプリでウインドウが左に寄る問題に対処し、起動と画面切り替えの通信待ちを減らしました。

## ダウンロード

Windowsにインストールする場合は `Bathjun-Setup-x64.exe`、同じPC内だけで試す場合は `Bathjun-Portable-x64.zip` を使ってください。手動更新の手順は[管理者向けガイド](https://github.com/Slfinside/bathjun/blob/main/docs/administrator-guide.md)を確認してください。

ブラウザーの操作はChromiumとWebKitで確認しています。時刻ピッカーの表示は端末とブラウザーによって異なります。
