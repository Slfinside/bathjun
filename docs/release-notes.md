ふろじゅん **v2.0.0** の安定版です。**v1.3.0からの変更点**をまとめています。インストーラ版とZIP版に同じ変更を収録しています。

## v1.3.0からの主な変更

- **週間スタンプカードと報酬**：日曜〜土曜の7日間の入浴記録を管理します。成功はお風呂マーク、失敗は黒いバツ、未確定はグレーのハイフンです。様子見の連続日数による判定、翌日の入浴による保留分の解決、達成時の固定報酬・ルーレット・両方の組み合わせに対応しました。
- **アイテムとプレゼント**：順番抜かし、時間延長、抽選確率UP、ガード、おふろスタンプ、スタンプのインクを追加しました。管理者からの配布、本人の受け取り、持ち物、配布履歴、使用条件・出現比率・機能全体のオンオフを設定できます。インクは今週・先週の今日までの未確定／失敗の日に使えます。
- **自動予約と事前希望**：曜日・開始時刻・長さの一覧から、1曜日ずつ予約・様子見・無効を設定できます。自分の番で自動入力し、空いていれば確定、重なれば希望として残します。自動入力した予定には印を表示します。固定順では前日に入力した希望も当日0:00から順番に確認します。抽選方式は当日の手動抽選を待ちます。
- **日付と朝の予約**：「今日」と抽選は日本時間0:00で切り替えます。予約・スタンプは開始時刻と区切り（初期7:00）で所属日を決め、朝の前日予約を確認しながら当日分を準備できます。明後日まで希望・様子見を共有でき、区切りをまたぐ予約や異なる日付同士の重複も扱います。
- **完了報告と再予約**：本人の画面からの完了報告を管理者の共通設定にしました（初期オフ）。ダッシュボードからの報告は引き続き利用できます。未報告の場合は、有効な報告期限後から所属日の受付終了までにホームを開くと、予約を取り直すか確認します。新しい予約を保存するまで元の枠は残ります。
- **通知**：希望の結果、順番、入浴前、完了報告のお願い、順番抜かし、つつくに対応しました。初期オンは「希望の確定失敗・入浴前・完了報告のお願い・つつく」の4種類です。個人の保存済み設定は維持します。入浴前の分数も本人が変更できます。
- **ダッシュボードと管理画面**：現在・次の人、残り時間、時計、QR、右側の縦長スケジュールを表示します。簡易／詳細の切り替え、簡易表示からの完了報告、希望の重複表示、絵文字、時間・分の表記、同梱日本語フォントに対応しました。管理画面のタッチスクロールと更新時の互換性エラーも修正しました。
- **使い方ガイドと読み込み**：初回登録後の案内、持ち物・スタンプカードの「？」、メニューのヘルプを追加しました。詳細は折り畳み、説明は開いたときに読み込みます。Webフォントは全字形を保持したまま分割し、通常画面の取得量を約4.5MBから約228KBへ削減しました。画面ファイルの圧縮・キャッシュ確認にも対応しました。
- **不具合修正**：通知重複、送信途中のログアウト・通知解除の取りこぼし、別端末による曜日設定の上書き、アイテム変更時の入力消失、抽選確率UPの再試行時の二重消費、通信中の画面更新、認証切れ後のパスキー一覧の残留などを修正しました。
- **日本語名**：「ふろじゅん」に戻しました。旧「ふろきゅ～」版からも更新できます。bathjunの識別子、保存先、共有URL、パスキーのRP IDは維持し、名前変更のためのデータリセットは不要です。

## ダウンロード・更新

- `Bathjun-Setup-x64.exe`：インストール版。サーバーを終了し、同じインストール先へ上書きしてください。
- `Bathjun-Portable-x64.zip`：インストール不要のローカル試用版。サーバーを終了して新しいフォルダーへ展開します。
- 各ファイルに `.sha256` を添付します。GitHubのSource code ZIP / tar.gzは実行用ZIPとは別です。

更新前にデータフォルダー（通常版 `%LOCALAPPDATA%\BathjunData`、ZIP版 `%LOCALAPPDATA%\BathjunTestData`）をバックアップしてください。メンバー・認証・予約・持ち物を保持して移行します。旧入浴時間帯の所属日は保持し、新しい区切りは更新翌日分から適用します。更新後は予約画面を再読み込みしてください。外部公開は「固定URLで外部公開」から起動します。

## 検証と確認範囲

API・ドメイン239件、Chromiumの15の操作シナリオ、連続28,000操作、Windowsの描画・設定・更新判定、インストーラとZIPのビルド・同梱内容を確認しています。名称・版番号の変更後も同じ検証手順を実施しています。

Windowsの実消灯／点灯は、専用スレッド・絶対時刻タイマー・実画面状態の通知・再試行・診断ログで扱います。**実機iPhoneへのPush到達や、実機パネルの消灯・自動点灯はこの環境では未確認です。** Windows Helloの再サインイン条件やTailscaleのRun unattendedも確認してください。[実機確認の手順](https://github.com/Slfinside/bathjun/blob/v2.0.0/docs/screen-off-investigation.md)を収録しています。

配布ファイルは未署名です。起動入口の一本化、自動バックアップ・復元、端末単位のログイン管理、配布元から独立した更新署名は未搭載です。
