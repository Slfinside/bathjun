予約画面とダッシュボードのフォントを **Noto Sans JP** に統一しました。通常・太字の同じフォントをアプリに同梱し、利用時に外部フォントサービスへ接続しません。

ダッシュボードも予約画面と共通のロゴ、緑・オレンジ、丸いカード、メンバーのアイコンへ整えました。常時表示に使う暗色と位置の移動、不在時の大きな表示は維持しています。明るさセンサーでの自動消灯は追加していません。

- インストール版：`Bathjun-Setup-x64.exe`
- このPC内のテスト用ZIP：`Bathjun-Portable-x64.zip`
- ソース：Source code（実行用ZIPとは別です）

v1.1.1の管理画面から「最新版を確認」→ダウンロード→「インストーラーを選んで更新」が使えます。同じフォルダーに `.exe.sha256` を置くと照合します。古い版からは「サーバーを停止して終了」後に上書き実行してください。データは保持します。

バックアップ・復元などはv2.0.0の予定であり、この版には含めていません。
