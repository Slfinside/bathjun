ふろじゅん — Windows用

【管理者権限なしのテスト】
ZIP版はすべて展開し「はじめる.cmd」を開きます。
インストーラー版は本体だけ選べば管理者権限なしで導入できます。
デスクトップの「ふろじゅん」は、このPC内だけのモードで起動します。
本体のみではTailscaleや外部公開は使いません。
ZIP版のテストデータは BathjunTestData、通常版は BathjunData に保存します。
学校側で実行自体が禁止されている場合は管理者へ確認してください。

【外部公開する場合の初回設定】
Tailscaleの初回導入にはWindows管理者の許可が必要です。
ローカルサーバーを停止し、スタートメニュー「固定URLで外部公開」を開きます。
家族の合い言葉の設定後、Tailscaleの無料アカウントへサインインし、HTTPS/Funnelを許可します。
接続確認後に家族用リンクが表示されるので、家族だけに共有してください。
各自が初回に名前・復旧用の個別パスワードを設定し、パスキーを登録します。

【二回目以降】
ログイン状態が残っていればそのまま開きます。
ログアウトしていても「パスキーでログイン」を選べば、Face ID / Windows Hello / PINで
本人を確認し、家族共通と個別の両パスワード入力を省略できます。
個別パスワードは、パスキーを使えないときの復旧用として残しています。
パスキーの秘密鍵や顔・指紋の情報を、このサーバーに送信・保存することはありません。

【iPhoneの通知】
iOS 16.4以降。Safariで家族用リンクを開き、ホーム画面に追加します。
追加したアプリでログインし、「通知を受け取る」を押して許可してください。
家族のiPhoneにTailscaleアプリを入れる必要はありません。

【サーバーの操作画面】
起動すると、ログ用のターミナルに加えて小さい専用の操作画面が開きます。
「稼働状況」タブ: 接続状況、家族用リンク、コピー、予約画面を開く、画面だけ消す、停止。
「設定」タブ: メンバー名・人数・利用状態、入浴時間帯、抽選時間、予約の最小・最大・刻み幅、抽選/固定順。
固定順はメンバー表の上から順です。選択行を上下に動かして保存します。
時間帯と予約順の設定は翌日分から反映します。名前・利用状態はすぐ反映します。
今日の抽選や既存の予約を、設定変更で書き換えることはありません。

AC電源につないで、稼働状況の「画面だけ消す（サーバーは継続）」を押してください。
1秒後に画面が消え、タッチ・マウス・キーボードで戻ります。
サーバー稼働中だけWindowsへ自動スリープを防ぐ要求を出し、終了時に解除します。
電源プランやレジストリを常時スリープ禁止に書き換えることはしません。
電源ボタン・カバー閉じ・スタートメニューからの手動スリープは防げません。
Modern Standby対応PCではバッテリー動作中の要求に制限があるため、AC電源が必要です。
Windows実機での消灯・スリープ防止は未検証です。最初にAC接続で動作を確認してください。

操作画面の×は通知領域にしまう操作です。サーバーとスリープ防止は継続します。
通知領域のアイコン、またはデスクトップの「ふろじゅん」から操作画面に戻れます。
終了は「サーバーを停止して終了」、またはターミナルで Ctrl+C。
操作画面が異常終了した場合もサーバーを停止し、スリープ防止要求は解除されます。
初期設定で開いたブラウザーは閉じて構いません。
自動起動を選んだ場合も、Windowsへのサインインが必要です。

【入らない/様子見】
入浴しないと確定する操作ではありません。その日の予約順の末尾へ回ります。
複数人が選んだ場合は、選んだ順に末尾へ並びます。末尾の順番が来たら予約できます。
既存の未来の予約・希望がある場合は確認後に取り消します。
様子見中でも希望を共有でき、「通常の順番に戻す」で元の抽選・固定順へ戻せます。
抽選・固定順の元の結果自体は保存しているので、再抽選はしません。

【データ】
保存先: %LOCALAPPDATA%\BathjunData
家族用リンクは同フォルダの public-link.txt にも保存されます。
バックアップはアプリを停止してから、このフォルダごとコピーします。
更新・アンインストールでもデータは残ります。
「家族の合い言葉を変更」は、全員のログイン・通知登録・パスキー登録を解除します。
個別パスワード・予約・希望は残ります。

【固定URLについて】
Tailscale Funnelの無料固定URLを使います。登録したPCのTailscale登録・DNS名を
維持すれば、PCやアプリの再起動でも同じURLを使います。
PCのTailscale登録を削除したり、DNS名を変えたり、別の公開元に移したりすると、
パスキーの再登録が必要になる場合があります。
既存サービスと衝突しにくい公開ポート8443を使います。ルーターのポート開放は不要です。

【導入・削除】
Windows 10/11の64bit版向けです。WindowsのSモードでは実行できません。
Node.jsは同梱しています。Tailscaleは初回セットアップが公式から取得し、
「Tailscale Inc.」の署名を検証して導入します。インターネットと管理者の許可が必要です。
ふろじゅん本体はユーザー用フォルダに入ります。
Tailscaleは他のアプリでも使えるため、ふろじゅんを削除しても自動では削除しません。
不要になったらWindowsのアプリ一覧から別途削除してください。
更新・削除の前にふろじゅんを Ctrl+C で停止してください。

インストーラー自体は未署名のため、Windowsから発行元不明と表示される場合があります。
Windows実機のインストール・操作画面・消灯と電源制御、Tailscaleへのサインイン・公開、iPhone実機の通知・Face IDは未検証です。
パスキーはブラウザーの仮想認証器と実際の署名を使って検証しています。

【初期設定と予定表】
メンバーは初期状態では未登録です。設定タブで「追加する名前」に入力し、「メンバーを追加」→「設定を保存」を押してください。
抽選時間の制限は初期状態では無効です。設定で有効にできます。
時間設定の変更は翌日の夜から反映します。既存の登録メンバー・履歴は保持します。
予定表は15分目盛りで表示し、2時間以上の空きは前後の時刻付きの波線で省略します。
昨日の夜・今日の夜・明日の夜の表示を切り替えられます。
パスキーと通知の設定済み案内は隠れ、変更は「ログイン・通知の設定」から行えます。

【パスワード管理と全リセット】
サーバー操作画面の「パスワード・リセット」タブで行います。
現在のパスワード自体は表示できません。設定状態と、入力したものが正しいかを確認できます。
忘れた場合も、新しいパスワードを2回入力して変更できます。
個別変更はその人、共通の合い言葉の変更は全員のログイン・パスキー・通知登録を解除します。
「全データをリセット」は、確認画面で「リセット」と入力してから実行します。
メンバー・予約・希望・抽選・時間設定・パスワード・パスキー・通知登録が削除され、
家族用リンクも更新されます。管理画面から合い言葉とメンバーを設定し直してください。

【アイコンと事前希望】
未設定のアイコンは灰色の「？」です。初回パスワード設定で絵文字と色を選びます。
16色のプリセットと、スポイトマークからの自由な色指定・カラーコード入力を使えます。
後からの変更は、予約画面の「ログイン・通知の設定 → アイコンを変更」から行えます。
事前希望は順番が来て、ほかの予約・希望のどちらとも重ならなければ自動確定します。
重なりがある間は未確定のままです。未確定の希望もスケジュールに薄い色・点線で表示します。

【予約開始10分前の通知】
通知を有効にした本人の端末へ、予約開始10分前にも送ります。
時刻変更では新しい予定へ合わせ、キャンセル・様子見・ログアウト・通知解除では取り消します。
予約や通知登録が開始10分以内なら、開始前に限り即時通知します。
自動確定した事前希望も対象です。サーバー再起動後も予定を復元し、開始済みなら送りません。

【メンバー追加】
「設定」タブの「追加する名前」へ入力し、「メンバーを追加」を押します。
人数分を追加したら「設定を保存」を押してください。追加した人の「利用する」は自動でオンです。
名前欄へ入力したまま「設定を保存」を押した場合も、その人を取り込んで保存します。


【常時表示ダッシュボード】
「稼働状況」→「ダッシュボードを開く」。右上をタップ、または Esc / F11 で戻ります。
次の人・現在の人・スケジュール・メンバー状態・時計・外部公開用QRを表示します。
入浴中／入浴済は予約時刻からの判定です。実際の入退室を検知するものではありません。
表示中は自動消灯の抑止を要求し、表示位置を動かします。AC電源で使ってください。
人感センサーの設定は初期オフです。対応するWindowsセンサーがある場合、
在席時は詳しく明るい表示、不在時は次の人と開始時刻を大きく表示します。
顔認証カメラだけでは利用できません。カメラ録画やOSの輝度変更はしません。
非対応・判定不能の場合は通常表示を保ちます。
詳しくは app/docs/administrator-guide.md、予約する人は app/docs/user-guide.md を参照してください。
