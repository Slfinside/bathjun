ふろじゅん — Windows ローカルテスト版

【起動】
1. ZIPを「すべて展開」します。ZIP内から直接実行しないでください。
2. 展開したフォルダの「はじめる.cmd」を開きます。
3. 初回はテスト用の合い言葉を2回入力します。
4. サーバー操作画面と、このPCのブラウザーで予約画面が開きます。
5. 設定タブから、メンバー・時刻・固定順などを試せます。

Node.jsやTailscaleのインストール、管理者権限、サービスの登録は不要です。
セットアップや自動起動のレジストリ登録も行いません。
学校のポリシーでアプリやスクリプトの実行自体が制限されている場合は、
この版でも起動できません。管理者へ確認してください。制限を回避する機能はありません。

【範囲】
接続はこのPC内（127.0.0.1）だけに限定しています。
外部公開、同じWi-Fiの別端末からの接続、iPhoneへのプッシュ通知の確認はできません。
Windows Helloでのパスキー登録可否は、PC側の設定によります。
抽選・予約の時間制限は通常版と同じで、PCの時計は変更しません。
学校PCには本番用の合い言葉や予約を持ち込まず、テスト用データを使ってください。

【データと終了】
データ保存先は %LOCALAPPDATA%\BathjunTestData です。
通常版の BathjunData とは分離しています。
終了は操作画面の「サーバーを停止して終了」、またはターミナルで Ctrl+C。
テストデータが不要になったら、停止後に BathjunTestData フォルダを削除できます。
アプリ本体は展開したフォルダごと削除できます。

【対応環境】
Windows 10/11の64bit版。WindowsのSモードには対応しません。
.NET FrameworkはWindowsにあるものを使います。
同梱のアプリは未署名です。学校PCの実行許可や設定を変更することはありません。
Windows実機での起動・電源制御・Windows Helloは未検証です。

【初期設定と予定表】
メンバーは初期状態では未登録です。設定タブから追加してください。
抽選時間の制限は初期状態では無効です。設定で有効にできます。
時間設定の変更は翌日の夜から反映します。既存の登録メンバー・履歴は保持します。
予定表は15分目盛りで表示し、2時間以上の空きは前後の時刻付きの波線で省略します。
昨日の夜・今日の夜・明日の夜の表示を切り替えられます。
パスキーと通知の設定済み案内は隠れ、変更は「ログイン・通知の設定」から行えます。

【パスワード管理と全リセット】
サーバー操作画面の「パスワード・リセット」タブで行います。
現在のパスワード自体は表示できません。設定状態と、入力したものが正しいかを確認できます。
忘れた場合も、新しいパスワードを2回入力して変更できます。
個別変更はその人、共通の合い言葉の変更は全員のログイン・パスキー・通知登録を解除します。
「全データをリセット」は、確認画面で「リセット」と入力してから実行します。
メンバー・予約・希望・抽選・時間設定・パスワード・パスキー・通知登録が削除され、
家族用リンクも更新されます。管理画面から合い言葉とメンバーを設定し直してください。

【アイコンと事前希望】
未設定のアイコンは灰色の「？」です。初回パスワード設定で絵文字と色を選びます。
16色のプリセットと、スポイトマークからの自由な色指定・カラーコード入力を使えます。
後からの変更は、予約画面の「ログイン・通知の設定 → アイコンを変更」から行えます。
事前希望は順番が来て、ほかの予約・希望のどちらとも重ならなければ自動確定します。
重なりがある間は未確定のままです。未確定の希望もスケジュールに薄い色・点線で表示します。
